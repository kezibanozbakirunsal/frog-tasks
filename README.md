# Frog Tasks 🐸

Frog Tasks is a small Angular practice application I built while learning frontend development.  
The project helped me to understand **Angular components, routing and basic state management**.

---

## Features

- Simple task list
- Separate pages using Angular Router (Home, About, Settings, etc.)
- Basic navigation between views
- Practice area for styling and layout

---

## Technologies Used

- Angular
- TypeScript
- HTML & CSS
- Node.js & npm

---

## Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/kezibanozbakirunsal/frog-tasks.git

# Move into the project folder
cd frog-tasks

# Install dependencies
npm install

# Start the development server
ng serve
